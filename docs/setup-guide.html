Device Setup Guide

Follow the steps for your device's role in the LAN setup.

What is this device?
⚙️ One-Time Setup Do once ▼
1
Allow remote MySQL connections

Open MySQL Workbench → connect to Local instance MySQL80 → run these queries one by one:

CREATE USER IF NOT EXISTS 'root'@'%' IDENTIFIED BY 'your_mysql_password';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;

Verify it worked:

SELECT user, host FROM mysql.user WHERE user = 'root';
✅ Should show two rows: root | localhost and root | %
2
Open firewall ports

Open Command Prompt as Administrator and run both commands:

netsh advfirewall firewall add rule name="Capstone Port 3000" dir=in action=allow protocol=TCP localport=3000
netsh advfirewall firewall add rule name="MySQL Port 3306" dir=in action=allow protocol=TCP localport=3306
3
Find your LAN IP and share it with Device B
ipconfig

Look for IPv4 Address under your Wi-Fi adapter.

Your LAN IP
192.168.x.x
ℹ️ Give this IP to the Client Laptop — they need it to connect.
▶️ Daily Startup Every session ▼
1
Check MySQL80 service is running

Press Win + R → type services.msc → Enter

Find MySQL80 in the list. Status must be Running.

If not → right-click → Start

2
Open the Electron app

In the project folder, run:

npm start

Wait for both lines to appear:

✅ Database connected successfully!
🚀 Server running on http://localhost:3000
⚠️ Keep the app open the entire session — closing it disconnects Device B.
3
Log in and start working

Log in as your role (Deputy Officer, Kagawad, or Team Leader). Device B can now connect.

✅ Session Checklist ▼
Progress 0 / 4
🔧 Troubleshooting ▼
Port 3000 already in use
netstat -ano | findstr :3000

Note the PID, then:

taskkill /PID [number] /F
Access denied for root@%

Re-run the MySQL grant queries in One-Time Setup Step 1. Make sure you run all 3 lines.

Device B can't see shared data

On Device B → Settings → Database tab → confirm Host is this PC's IP, not localhost. Click Test Connection.

🔧 Troubleshooting ▼
Data doesn't match Server PC

Settings → Database tab → confirm Host is the Server PC's IP, not localhost. Click Test Connection → Save → restart.

Can't connect to database

Make sure the Server PC is fully started first. Check both devices are on the same WiFi. The Server PC's IP may have changed — ask them to re-run ipconfig.
