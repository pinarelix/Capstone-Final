# Discontinued native experiment

The user chose to retain the Electron interface on 2026-10-24. These files are preserved
as reference source only. They are not an active replacement, are not included in the
Electron build, and no .NET installation is needed to run the supported application.

Run `npm start` from the repository root. See
[desktop operation](../docs/ELECTRON_LOCAL_OPERATION.md) for current architecture and
network dependencies. The earlier implementation notes are historical, not a roadmap.
